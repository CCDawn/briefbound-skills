# Craft Baseline

数字规则层：给视觉参数可执行的默认值、生成方法和按语境调整的指引。这是默认起点而非禁令；与产品语境或视觉契约冲突时以契约为准，偏离默认值时写明理由。中文条目为本技能的中文变体约定，拉丁条目另注。

## 排版

| 参数 | 默认值 | 生成方法与调整 |
|---|---|---|
| 正文字号 | ≥16px | 次要文字最低 12px；移动端输入框 ≥16px，避免 iOS 聚焦自动缩放 |
| 字号阶梯 | 相邻档比例约 1.25-1.333 | 从正文向上乘出 display 档；向下用 0.875/0.75 做辅助层 |
| 行高 | 正文 1.7-1.9（中文），1.5-1.6（拉丁） | 字号越大行高越紧，display 可到 1.1-1.2 |
| 行长 | 中文 30-40 字/行，拉丁 60-80 字符 | 超长用分栏或加宽边距解决，不缩小字号 |
| 标题字距 | 中文 +0.02em，拉丁 display 可 -0.01~-0.02em | 中文不用负字距，方块字会粘连 |
| 字重配对 | 正文 400 + 标题 500-700 | 同页 ≤3 档；核对中文字体是否有对应字重，缺档回退最近一档 |

中文字体栈写法：西文在前、中文在后、泛型收尾，如 `"Inter", "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`——拉丁字形由西文字体渲染，汉字按平台回退（macOS 走 PingFang SC，Windows 走 Microsoft YaHei，Linux/Android 走 Noto Sans SC）。比较型数字加 `font-variant-numeric: tabular-nums`。

## 间距

- 刻度：所有间距取 4px 的倍数；≥24px 的区块节奏取 8px 的倍数。
- 比例节奏：区块间距 ≥ 2× 组内间距；容器外边距 ≥ 内边距，外小于内时层级感消失。
- 度量点：在对比强的边界之间量间距（如文字 x 高度或大写顶线），不在留白边缘量。
- 网格：内容页默认 12 列，槽宽同入 4px 刻度。

## 色彩

- 色板 3-5 色：背景、文本、accent 起步，状态色按需派生，不再多。
- 亮度分级生成法：先建 9-10 档中性灰阶，再以 OKLCH/HSL 固定色相、逐档调亮度生成品牌色层级；每个色板色的亮度值必须彼此错开。
- 容器差：背景与容器亮度差，暗色 UI ≤12%，亮色 UI ≤7%，超出会碎或糊。
- 中性色带轻微饱和：给灰阶加主色 <5% 的饱和度（HSB），暖或冷选一边不混用；文字用近黑近白（如 #1a1a1a/#fafafa），不用纯黑纯白。
- 状态色派生：成功/警告/危险由 accent 色相旋转或固定语义色得到，沿用同一亮度分级；状态不只靠颜色，加文字或图标。
- 暗色模式派生方向：亮度翻转而非色值反转；彩色在暗底上提亮降饱和；阴影换成 surface 抬升与半透明边框，边框/阴影/文字向背景色相染色；`<html>` 设 `color-scheme: dark`。

## 细节

- 阴影至少两层：ambient（大模糊低不透明度）+ direct（小模糊近色），边界再叠半透明边框；blur ≈ 2× 偏移；越近的元素阴影越锐、不透明度越低。
- 圆角：子圆角 ≤ 父圆角且同心；内圆角 = 外圆角 − 间距。
- 动效档位：微交互 100-200ms，位移/展开 250-300ms；入场 ease-out、离场 ease-in、位移用标准曲线；只动 transform/opacity，显式列出过渡属性，不用 `transition: all`；骨架屏出现延迟约 150-300ms、最短停留约 300-500ms。
- reduced-motion：尊重 `prefers-reduced-motion`，动效降级为淡入淡出或直接呈现；超过 5 秒的自动运动必须可暂停或关闭。
