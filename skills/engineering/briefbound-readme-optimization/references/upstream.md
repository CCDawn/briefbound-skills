## standard-readme（MIT）

- 来源：https://github.com/richardlitt/standard-readme
- 借鉴：README 章节规范与顺序（标题+一行描述、徽章、简介、安装、使用、维护者、贡献、许可证），以及"读者不读源码即可使用"的验收判据。
- 改编：按项目类型（技能包/脚本合集/网页应用/研究仓库）裁剪章节，中文优先，不采用其 npm 生态专属内容与徽章规范。

## NASA-AMMOS/slim · slim-readme（Apache-2.0）

- 来源：https://github.com/nasa-ammos/slim（static/marketplace/skills/slim-readme）
- 借鉴：五步工作流（查现有 README → 读清单理解项目 → 生成 → 逐节定制 → 验证清单）与"What/Why/How/Who"四问。
- 改编：删除"替换还是增强"的强制用户询问（改为按证据自行判断）；模板与检查清单按中文优先与多项目类型重写。
