# 通用评价

仅在没有 PR、项目风险、bug、复用选型等专项 owner，且用户需要评价一个方案、流程或输出时读取。普通明确任务由当前 owner 直接完成。

依据用户目标选会改变行动的维度；先定位对象与证据，只问无法从上下文得到且会影响判断的缺口。每个判断说明观察、影响和最小有效改进；证据足够就停止，不固定遍历矩阵。

默认给少量高价值建议，按收益、依赖与误改风险排序；完整审计按用户要求展开，不机械限制条数。区分事实、推断和未验证，避免“更完善”等无依据评价。

评价本身不授权实施。已有修复/优化许可时交最具体 owner 继续执行；不重复询问，不把评价变成另一套实施流程。输出结论、关键证据、改进建议与真正影响决策的缺口。
