# 图解品牌适配

仅在用户要求匹配品牌、已有项目视觉系统，或图解将进入已有品牌制品时读取。

先读取项目中的真实 token、字体和相邻制品；网站采样只使用用户提供或公开页面。形成 `paper`、`paper-2`、`ink`、`muted`、`accent`、`link` 及 display/body/mono 字体映射，并检查正文和细字对比度。强调色仍只用于一至两个焦点。

品牌结果属于当前任务。复制 `references/style-guide.md` 到任务目录并修改该副本或直接在产出 HTML 中替换 token；不要改已安装 Skill、全局 profile 或其他项目。说明采样来源、精确 token、字体可用性和降级字体。

中文内容优先选择覆盖完整的字体。远程字体无法保证离线加载时，使用目标环境已安装的字体并在真实渲染中确认。品牌色不足以表达状态时加入形状、线型或文本，不只依赖颜色。
